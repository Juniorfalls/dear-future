# Solving for X — 15s lesson

Structure adapted from the `write-script` skill (hook → concept → worked example →
common mistake → recap), compressed to one short.

## 开场导入 / Hook
"Today we solve for x."

## 概念讲解 / Concept
"Start with two x plus three equals eleven. Subtract three from both sides."

## 例题演示 / Worked example
"Two x equals eight. Finally, divide by two: x equals four."

## 易错点提醒 / Common mistake
"Whatever you do to one side, do to the other."

## 小结 / Recap
"Now you can solve it too."

Board takes the equation one transformation at a time; the voiceover states the
same operation before the line appears, and the chalk hand writes on the trigger
word.
